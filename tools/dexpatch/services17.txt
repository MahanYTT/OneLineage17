# LineageOS 24 (Android 17) services.jar patches. One "Class;:method[:value]"
# per line; all overloads of a method are patched to return at once
# (void / 0 / null / the given value). Built with:
#   python dexpatch.py services.jar patch services17_patched.jar $(grep -v '^#' services17.txt)

# "Destroying user 0 on volume null because we failed to prepare" and One
# UI's installd wiped the real user 0 app data and media of the test phone.
# Every call below acts on the REAL phone and must never run from Lineage.
#
